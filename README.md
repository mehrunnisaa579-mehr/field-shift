# 🌾 Field Shift: Adapting Farms Across Iowa's 99 Counties

> **2026 NASA Space Apps Challenge Submission** — An interactive geospatial decision-support dashboard designed to simulate, evaluate, and optimize climate-resilient agricultural strategies across all **99 counties in Iowa**.

🔗 **Live App:** [field-shift-steel.vercel.app](https://field-shift-steel.vercel.app)

---

## 📖 What is Field Shift?

Agricultural regions face increasing climate volatility, requiring farmers and policymakers to balance crop profitability with long-term environmental sustainability. **Field Shift** bridges climate data with county-level spatial intelligence, allowing users and judges to:

- **Explore All 99 Iowa Counties:** Click or hover over any county on an interactive choropleth map to inspect localized climate history, crop yields, and resilience metrics.
- **Simulate Adaptation Scenarios (R0–R3):** Compare baseline farming practices (`R0`) against three progressive adaptation strategies (`R1`–`R3`) to see projected impacts on yield, net return per acre, and drought stress.
- **Customize Judge & Policy Weights:** Dynamically adjust priority sliders (**Water**, **Soil**, and **Profit**) and set a **Profit Guardrail** to automatically identify the optimal adaptation scenario for each county.
- **Analyze Multi-Dimensional Performance:** Inspect 10-year historical climate and yield trends alongside a 5-axis **Spatial Intelligence (SI) Radar** (Water, Soil, Climate, Profit, Carbon).

## 🛰️ Data Sources: Real vs. Calibrated Demo Model

To ensure full scientific transparency, Field Shift separates live/real geospatial and climate integrations from its calibrated scenario simulation layer:

### - Real & Live Integrations
- **County Boundaries (`public/data/iowa-counties.geojson`):** Real geospatial polygons, areas, and FIPS codes for all **99 Iowa counties**, derived from **U.S. Census Bureau** cartographic boundary datasets.
- **NASA POWER API (`/api/climate/[fips]`):** Live integration (no API key required) fetching annual agricultural climate variables from **2016 to 2025** at each county's geographic center:
  - `T2M` — Temperature at 2 Meters
  - `PRECTOTCORR` — Bias-Corrected Total Precipitation
  - `ALLSKY_SFC_SW_DWN` — All-Sky Surface Shortwave Downward Irradiance
  - *Automatic Fallback:* Displays a **`NASA POWER live`** badge when live data is fetched, or seamlessly falls back to bundled climate history (`Demo climate data`) if offline.

### - Calibrated Demo Model (`lib/mock-data.ts`)
- **Yields, Economics & Scenarios:** Corn and soybean yields, net return per acre, drought stress, Spatial Intelligence sub-scores, and `R0–R3` scenario multipliers are generated by a deterministic, FIPS-seeded synthetic model calibrated with realistic regional gradients.
- **Future Data Pipeline:** Datasets such as **USDA NASS**, **SSURGO** soils, **SMAP**, and **MODIS** are structured as next-phase pipeline targets. To connect live pipeline outputs, swap `buildSyntheticCounty` in `lib/server/counties.ts`—no UI changes required.

## 🚀 Running Locally

No environment variables or API keys are needed to run the application:

```bash
# 1. Clone the repository
git clone https://github.com/mehrunnisaa579-mehr/field-shift.git
cd field-shift

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser. To verify TypeScript types:

```bash
npm run typecheck
```
